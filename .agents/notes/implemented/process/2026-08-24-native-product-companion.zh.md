# Agent Note：新增原生状态驱动产品伙伴

状态：已实现

[English](2026-08-24-native-product-companion.md) | 中文

## 问题

Xiaozhuang DSH 已经包含多个实用原生插件，但产品里还没有一个能跨页面持续存在的角色，也缺少一种把后台 Agent 状态变成轻量环境提示的方式。现有 DSH 宠物插件已经证明，空闲、工作、等待、完成、错误、拖动和睡眠状态容易理解；但它们更完整的喂养、货币、成长、小游戏、多宠物和第二聊天系统会重复 DSH 主流程，并新增很大的状态领域。

如果把伙伴放在某个目录、对话或设置组件内部，拥有者卸载时它就会消失。纯装饰动画也只会占用空间，无法帮助用户注意待批准任务或后台工作。

## 决定

新增双端原生插件 `@deepseek-ai/dsh-client-ui-product-companion`。浏览器端向可叠加的 `shell.overlay` 插槽贡献一个根作用域入口，因此伙伴可以持续挂载在所有应用栏位与页面之上，不替换任何布局拥有者。它消费现有会话列表投影，以确定性方式派生工作、等待、短暂完成、空闲和休息状态；不发起模型请求，也不保存第二份会话真相。

Host 端只提供 `/v8/` 下 124 张白名单内的不可变 PNG。内置 ImageGen 保留同一个明确为 29 岁的成年角色、用户认可的脸型、高挑纤细和自然比例，以及 DeepSeek 鲸系首饰和非露骨的性感时装语言。四张通过验收的趴姿源图提供 20 张输入框趴姿、12 张趴姿专注、12 张趴姿等待和 12 张趴姿完成原画；此前通过验收的六张传送门原画取代已经停用的自然爬行。语义状态共享同一镜头、人物尺度和输入框接触基线；传送门在进入 V8 前会统一到同样的 295 px 人物最长轴和 343 px 底部基线。可复现构建保留完整格子，完成品红色键与残片清理，再用 contain-fit 统一到 384 × 384 透明画布，不拉伸人体。同一组清理后帧会确定性生成夜航黑配色。帧素材测试会拒绝不透明边缘、蓝黑轮廓不一致、语义循环几何漂移，或者改变人物体感尺寸与基线的传送门素材。浏览器会在播放前解码当前皮肤的全部 62 张原画帧。

可见界面无卡片边框，并提供标准、放大两种光学尺寸，运行样式不会给生成轮廓增加投影。角色永久锚定在实测输入框右侧正上方；每个尺寸按原画透明轮廓独立标定底部内缩，让可见身体贴住边框却不覆盖输入文字。所有语义状态都保持趴姿。发送消息或页面回流改变输入框几何位置时，插件使用 `MutationObserver`、可用时的 `ResizeObserver`、滚动监听和短时 `requestAnimationFrame` 测量窗口更新目标锚点；澜汐先在旧锚点站起并播放六张传送门原画，只在门完全遮住人物时切换根节点坐标，再在最新目标上反向播放同一组原画并回到对应趴姿。一次过渡中的多次几何变化会合并到最新目标。根节点框、图片层、人物最长可见轴和底部基线全程固定，CSS 不再提供移动过渡或任何缩放；输入框不动时角色也不会位移。用户拖动、自由放置和空闲换边仍然关闭。单击、双击和右键拥有独立持久化绑定；默认复用产品现有的聚焦输入框、继承当前工作区新建对话，以及包含新建／聚焦／关闭的 `Menu`。单击延迟 240 毫秒确认，避免双击时错误执行第一次单击。所有动作从 24 fps 曝光表读取，预解码原画只在一个始终不透明的图片层上替换。

GitHub 调研同时改变了状态和播放契约。OpenAI Codex 把命名轨道映射到运行、等待、审查和失败等语义通知，并显式定义素材索引、单帧时长、循环点和回退；VS Code Pets 只在状态切换时更换动画源，位置和行为由独立状态机推进。两者都说明，持续产品状态和连续位移不能靠反复替换无关的整身姿势来模拟。DSH 只采用真正解决主任务的部分：稳定语义姿势、合成层连续运动、紧凑的实时阶段与浏览器实际观察到的用时，不显示假百分比，不读取提示词或生成正文，也不新增 Agent 调用。

根作用域 store 同时交给 `shell.overlay` 和独立 `settings.section` 使用。设置页统一管理蓝黑皮肤、标准／放大尺寸、三种快捷动作、角色显示和状态提示；关闭后，同一个显示开关就是恢复入口。伙伴只观察权威会话阶段，以及真实输入框是否非空的布尔值，绝不保留消息正文。任务数字直接把既有会话投影展开成依次出现的独立气泡；选择气泡只切换当前会话，不关闭任务层，数字开关、Escape 和外部点击统一负责带动画收起。设置弹窗出现时角色主动退场，关闭弹窗后再回到输入框。旧持久化记录默认继续显示，并采用放大、聚焦／新建／菜单绑定。设计明确排除自由或纵向定位、手动位置持久化、喂养、成长、货币、游戏、状态卡片和第二聊天框。

## 考虑过的替代方案

**放进目录内部。** 这能让默认姿势更像趴在目录上，但目录收起、进入设置或使用其他布局时伙伴会消失。Shell overlay 在保持视觉位置的同时实现真正跨页面。

**增加独立宠物后端和模型对话。** 这可以提供更多性格，但也会产生另一套提示词、历史、成本和失败路径。现有会话投影已经包含真正有用的产品信号。

**分别生成每一张夜航黑帧。** 这能获得更多局部变化，但会不断漂移面部、肢体和单元格边界，也无法让蓝黑两套帧严格同步。最终流程只在背景清理后对蓝色主导的服装区域做受控调色，肤色、白色区域、透明度和青色高光保持不变。

## 影响

伙伴可以作为一条 Loader 插件配置独立启用或移除。它会提示等待任务、用真实观察时间映射运行工作、庆祝实时完成，并始终依附在用户与 Agent 交换工作的输入区。运行时发布 124 张压缩 PNG；保留的角色母版与五张通过验收的源图只作为可审计开发素材，不会随包发布。后续新增状态仍必须从已有权威投影派生，不能再创建第二套任务状态机、恢复用爬行移动根节点，或让鼠标移动驱动角色。
