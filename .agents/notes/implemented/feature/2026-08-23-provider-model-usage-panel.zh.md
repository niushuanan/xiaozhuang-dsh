# Agent Note: 多厂商模型用量面板

Status: implemented

[English](2026-08-23-provider-model-usage-panel.md) | 中文

## Problem

会话标题栏原本用大号行表展示厂商额度；内容形状不一、重复分隔线、冗余返回键、Logo 圆角不一致，也没有会员信息。它还把已登录的 ChatGPT 订阅误写为 CODEX，并把模型专属五小时桶混进账号视图。

## Decision

`@deepseek-ai/dsh-client-ui-provider-quota` 用一个 520px 的中文 2×2 卡片面板统一呈现 DeepSeek、KIMI、GLM 与 GPT，厂商品牌名和官方套餐名保留英文。每张卡片的真实品牌图片都使用 8px 容器圆角和 6px 图片圆角；KIMI 使用官方填充应用图标，GLM 使用 Z.ai 官方 Z 标记，GPT 使用 OpenAI 标记。DeepSeek 只展示一个账户余额，不展示 Cash/Bonus 拆分。页头只保留刷新图标，不再放内部返回键；现有标题栏入口本身即可收起面板。

会话标题栏入口改用专门生成的“用量强度”资产：三条钴蓝色容量柱与一条轨道式活动曲线交叉。它取代黄色状态点，后者的警告语义会让正常的产品入口显得不健康。厂商失败仍会在面板内明确显示，但不再决定入口的身份。优化后的 64px 透明 PNG 会嵌入客户端 bundle，保证插件离线运行；母版与运行尺寸源文件则保留在插件 `assets/` 目录。

额度线条只承担明确语义，不作装饰。每个五小时或本周指标都有可见的灰色总量底轨，只有大于 0 的已用部分才显示蓝色，并直接显示百分比和北京时间的绝对重置时刻。同一张卡片内用一条细线分开五小时与本周，不同厂商则用轻量卡片边框区分。0% 时如果厂商没有返回 `nextResetTime`，面板会明确说明当前暂无重置时间，不会自行猜测。

Host 与客户端启动时都不会执行提供方请求。用户首次打开面板时才请求快照，随后打开会复用 Host 的五分钟缓存。刷新图标明确绕过缓存，打开的面板则每五分钟静默刷新。Codex app-server 的 stdin 错误只会结算 GPT 提供方请求，不能作为未处理的流事件逸出并终止 Web Host。标题栏入口、外部点击和 Escape 都可关闭面板。

DeepSeek 把 `~/.claude/multi-gateway/config.json` 中选定的 Key 视为账户真源；仅在该 Key 不存在时，才把环境变量和 `~/.dsh/.env` 作为迁移兼容回退。KIMI 在重置后的官方响应缺少 `used` 时，使用 `limit - remaining` 还原用量，并优先采用官方账号名称 `Allegro`，而不是内部枚举 `LEVEL_ADVANCED`。GLM 返回 `Pro`。GPT 按官方 app-server 协议依次执行 initialize、`account/read` 与 `account/rateLimits/read`，显示 `Pro · 20X`，并且只公开主账号的本周窗口。快照不包含邮箱或认证材料。

产品名在 HTML、文档标题和侧边栏回退值中固定为 `DeepSeek Harness`，普通本地构建不再能把用户可见品牌改成 `DSH Local Build`；官方品牌插件仍可以替换这些回退值。

## Alternatives considered

**直接读取 Codex 认证文件。** 否决，因为那些文件是凭据，不是额度接口。本地 app-server 已经代表当前桌面登录账号，并且无需把 token 复制进插件即可返回限额事实。

**把 `codex_*` 模型桶合并进 GPT 账号限额。** 否决，因为用户需要的是订阅账号视图，而主桶当前只提供本周用量。模型专属五小时桶是另一个产品事实，混入会误报账号限额。

**在 Host 或客户端启动时预热全部提供方。** 否决，因为即使用户从不打开模型用量，厂商网络请求与 Codex 子进程也会和会话加载、模型切换及首条消息争抢资源。按需加载保留完整功能，后续打开仍然优先使用缓存。

**继续把警告状态点当作用量图标。** 否决，因为黄色表达的是注意，而不是模型消耗，并且没有可识别的用量隐喻。专属 raster 资产能让紧凑入口保持辨识度，也无需扩充图标库或用 CSS 伪造图稿。

## Consequences

当前机器可以打开按需加载的四厂商视图，明确手动刷新，并让打开的面板定时更新。首次打开需要等待提供方结果；启动过程不再依赖厂商延迟，后续打开复用缓存。标题栏入口表达的是模型用量，而不是警报。用户可见的 DeepSeek 值跟随用户选定的账号。KIMI 与 GLM 展示五小时和本周用量；GPT 只展示本周。Codex 监测仍依赖本机二进制和已登录的 ChatGPT 账号。厂商接口与公开品牌素材仍是外部依赖；单家失败只影响该卡片。

## Verification

定向组件测试覆盖中文缓存优先面板、手动刷新、仅显示余额的 DeepSeek 卡片、会员标签、语义进度条、绝对重置时刻、GPT 仅本周、标题栏入口收起与嵌入式 PNG 入口资产。纯映射测试覆盖 KIMI 的 remaining 回退与 GPT 本周窗口过滤。包级 bundle 和完整官方构建通过。真实 `127.0.0.1:3080` 路由返回四家实时报告；应用内浏览器实测面板为 520×330，面积比最初 760×459 减少 50.8%，并验证两个 0% 进度条均为全灰、没有蓝色子条，全部重置文本完整显示，刷新／收起正常，缓存优先打开为 289ms，全新标签页零控制台错误。修订后的真实页面把生成式入口以 16×16 渲染，其嵌入源为 64×64，且控制台错误为零。设计 QA 把改版前真实截图和修订后的真实面板放在同一输入中比较。
