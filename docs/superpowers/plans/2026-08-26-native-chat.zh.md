# 原生聊天实施计划

[English](2026-08-26-native-chat.md) | 中文

**目标：** 在不开发第二套对话产品的前提下，新增一个即刻可用、无文件夹、无工具权限的原生聊天流程。

**设计：** [`docs/superpowers/specs/2026-08-26-native-chat-design.zh.md`](../specs/2026-08-26-native-chat-design.zh.md)

## 1. 用定向测试钉住产品约定

为侧边栏双入口、`agentPreset: chat` 创建透传、空白聊天复用、独立聊天历史分组和无文件夹的精简对话姿态增加高价值测试，并在实现前确认失败。

## 2. 增加持久的聊天能力边界

随产品发布一个只包含完整对话人格的内部 `chat` preset。扩展客户端 Session 创建接口，透传 Host 已支持的 Agent preset 参数，并把 Host 确认的 preset 立即写入列表行。

## 3. 组合原生聊天插件与界面姿态

由侧边栏声明主操作 slot，把新会话改为开始工作，并挂载 `ui-chat` 贡献的开始聊天操作。复用空白聊天或在合并并发点击后创建、打开新聊天。把聊天会话投影到独立历史分组；去掉工作区、preset、权限和添加命令控件，保留现有对话和模型界面。

## 4. 文档与真实路径验证

更新包级和根目录双语 README、已实施 Agent Note、配对记录与 `PROJECT_CONTEXT.md`。运行定向测试、类型检查和构建，然后在本地产品中完成开始聊天、发送消息、从历史返回，并确认普通工作会话不受影响，最后提交并推送。
