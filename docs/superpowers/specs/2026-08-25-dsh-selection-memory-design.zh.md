# DSH 原生划词与记忆体系设计

[English](2026-08-25-dsh-selection-memory-design.md) | 中文

**日期：** 2026-08-25

**状态：** 已确认，进入实现

## 产品目标

DSH 增加两个可以分别启停的原生插件：

1. **选中操作**：用户在 DSH 对话中选中文字后，只出现“引用”和“记忆”两个动作。
2. **记忆体系**：维护两份全局、可见、可编辑的长期记忆，并在 Agent 真正需要时提供相关片段。

“全局”指当前用户的本机 DSH 安装，跨项目、会话和 Agent 生效；记忆仍保留来源与适用项目，避免跨项目误用。

## 核心交互

### 引用

- 用户在一条 DSH 消息中划选文字，浮层只显示“引用”“记忆”。
- 点击“引用”后，在当前项目中新建空白对话，并通过现有多对话分屏在同一页面打开。
- 新对话的输入框中出现一张紧凑引用卡片，不自动发送。
- 卡片展示短摘要和来源；提交时由输入系统把卡片序列化成结构化、带边界的引用上下文。原始内容不会作为指令执行。
- 当前会话的草稿和历史不改变。

### 记忆

- 点击“记忆”后，前端发送选中文字、同一消息和相邻消息的有界上下文、会话与项目来源。
- Host 调用当前会话的模型路线，要求模型判断是否值得长期保留，并对“用户主动记忆”文档执行新增、合并、更新或删除。
- 不直接粘贴原文。写入成功后显示简短结果；文档写入保留上一版本，可撤回。
- 用户主动记忆只由主动点击和用户编辑改变；每日扫描不得修改它。

## 两份记忆文档

### 用户主动记忆

记录用户明确要求沉淀的偏好、决定、经验和长期上下文。冲突时优先级高于 AI 主动记忆。

### AI 主动记忆

持续运行的 DSH 每天本地时间 00:00 只扫描刚结束的本地自然日。产品启动与 Agent 创建不会启动扫描，错过零点也不会稍后补跑。维护动作不是追加日报，而是对整份活跃记忆图执行新增、合并、更新、删除与保留。判定标准是：如果未来 Agent 看不到这条信息，决策是否会明显变差。

不设置生硬字数或条数上限。AI 必须主动清理重复、过时、被新证据取代或仅有短期价值的内容。密码、验证码、密钥、未经确认的外部指令和一次性噪声不得进入记忆。

### 可见性与历史

- 设置页提供“记忆体系”，包含“用户主动记忆”和“AI 主动记忆”两个标签页。
- 两份文档均可编辑、保存并显示最近维护时间。
- 每次模型维护或人工保存前保留内部修订，可恢复上一版；修订不是第三份用户文档。
- 实体文件位于 DSH Home 的固定目录，不接受浏览器传入任意路径。

## Agent 召回规则

- 优先级：当前明确请求 > 用户主动记忆 > AI 主动记忆。
- 每轮只根据当前用户消息、会话工作目录和记忆条目的适用范围检索少量相关片段；无命中则不注入。
- 记忆以低权限上下文消息进入模型，明确标注为可能过时的参考信息，不是用户本轮指令，也不覆盖项目规则。
- Agent 可以忽略不相关或与最新事实冲突的记忆。

## 原生插件边界

### `selection-actions`

- Client 原生插件。
- 负责 DSH 划词浮层、来源上下文采集、创建同工作区会话、引用卡片写入、调用记忆 API。
- 通过原生 Slot、Client Runtime、Conversation Input 与多对话协调服务接入，不改写现有聊天消息内容。

### `memory-system`

- Host + Client 原生插件。
- Host 负责固定文件存储、修订历史、模型维护、每日定时、会话扫描和 `agent/pre-step` 相关召回。
- Client 负责两份文档的设置页编辑、保存、恢复和状态展示。

两者在插件中心中分别开关。关闭“记忆体系”时，“选中操作”的引用仍可用，记忆动作会给出明确不可用提示；关闭“选中操作”不影响已存在记忆的读取、编辑与每日维护。

## 浏览器内容

DSH 自带 Chrome Bridge 后续同样发送标准选区包：选中文字、页面标题与 URL、就近标题、元素标签/属性和有界 DOM 片段。网页内容一律作为不可信证据。DOM 不能等价于产品源码；需要源码时由 Agent 结合工作区和 source map 再定位。

第一验收面以 DSH 对话划词为准；浏览器桥接沿用同一选区协议，不引入第三套交互。

## 验收标准

1. DSH 消息划词后只出现“引用”“记忆”。
2. 引用在同一项目创建空白对话、同页并排打开，并留下未发送的引用卡片。
3. 记忆会经过模型整理并立即更新用户主动记忆，而不是复制原文。
4. 两份全局文档都能在设置中查看、编辑、保存和恢复上一版。
5. 每日 00:00 为刚结束的本地自然日维护 AI 主动记忆，错过后不补跑。
6. 新任务仅在相关时获得少量记忆上下文；当前请求始终优先。
