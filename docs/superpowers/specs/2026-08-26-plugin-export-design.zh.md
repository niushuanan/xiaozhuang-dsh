# 插件选择导出设计

[English](2026-08-26-plugin-export-design.md) | 中文

## 产品契约

插件导出属于现有的**小庄的插件**页面。它是目录级操作，不是另一个可导出的插件，因此页面新增**导出插件**操作，并继续作为用户管理这些能力的唯一入口。

用户点击后直接在当前列表进入选择模式。每个可导出条目出现复选框；**全选 14 个**始终指目录中的全部小庄能力，不受搜索和当前启停状态影响。工具栏显示已选数量、支持取消，未选中任何条目时不能导出。选择期间不提供运行开关，避免导出操作意外改变当前产品。

## 压缩包契约

一次点击下载 `xiaozhuang-dsh-plugins-<timestamp>.zip`。压缩包包含：

- 面向接收者的 `README.md`；
- 面向安装 AI 的 `AGENTS.md` 和 `INSTALL.md`；
- `manifest.json`，记录源码 commit、所选目录条目、Cordis 行、包根目录、排除项和文件哈希；
- `payload/<plugin-id>/...`，保存所选源码和可直接运行的构建产物。

Host 只按插件 id 查询封闭目录，浏览器不能提交文件路径。仓库内原生包导出源码、manifest、构建后 JavaScript 和运行时真正使用的素材；本机 Profile 包导出代码，但排除 `node_modules`、Git 元数据、测试、缓存、凭据、历史记录和用户数据。ZIP 全程在内存生成，不在电脑上残留另一份暂存副本。

## AI 安装与冲突兜底

安装 AI 先检查目标 DSH checkout、项目指令、版本和未提交改动，再逐个安装所选包与 Cordis 行；它必须保留目标数据和设置，只执行覆盖这些能力的必要检查，不能整体覆盖 checkout 或 DSH Home。

目标版本的包结构或公共组装方式不同时，AI 可以调整路径、import、package manifest、Slot 和 Cordis 行，以适配目标版本。它必须保留 manifest 中的用户可见行为、记录每项适配；如果无法安全合并，则停止并明确报告。禁止破坏性重置、复制凭据、替换历史记录或删除无关插件。

## 归属

`ui-plugin-catalog` 是一个原生 Host／Client Cordis 包。Host 负责插件开关、协作者配置、本机导出 API、目录校验、文件收集和 ZIP 构建；Client 贡献现有的**小庄的插件**设置区，并负责搜索、选择、进度、下载和反馈。Web bundle 原生挂载这个包，但它不会出现在自己的导出目录中。
