# 设置页面视觉统一设计

## 目标

让“设置 → 侧边卡片”回归 DeepSeek Harness 现有设置体系，并统一各独立设置页顶部标题的字号、位置和说明文字节奏。

## 已确认设计

- 删除侧边卡片页中的 `DSH-better-sidebar` 与版本标识，不向用户暴露插件包身份。
- 页面顶部使用“侧边卡片”黑色粗体标题，标题为 20px / 28px / 600，说明为 13px / 20px。
- “常规”“侧边栏内容”“文件预览”作为自然分区，不使用整块圆角边框或背景包裹。
- 常规设置使用无外框的列表行和轻分割线；侧边栏内容与文件预览也使用列表式条目，只有展开区域使用轻背景强调，不再叠加大卡片。
- 数量是次要信息，使用普通弱化文字，不做胶囊。
- 开关保持 36×20；关闭时采用无描边中性灰轨道和白色 16px 圆点，开启时采用产品当前黑色轨道，行为、语义和持久化协议不变。
- 独立设置页复用一个共享标题组件，允许页面提供说明和右侧操作；不改变页面业务内容、导航文案或数据逻辑。

## 验收

- 侧边卡片页看不到 `DSH-better-sidebar`、版本号和三块外围大框。
- 侧边卡片关闭开关和“小庄的插件”等页面的关闭状态视觉一致。
- 设置目录中的独立页面标题使用同一字号、行高、字重和顶部起点。
- 侧边卡片开关、宽度、兼容模式、内容启停、展开设置和新增插件入口继续可用。
