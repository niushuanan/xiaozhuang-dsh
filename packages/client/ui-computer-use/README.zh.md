# @deepseek-ai/dsh-client-ui-computer-use

[English](README.md) | 中文

原生 Computer Use 的 Web 展示插件。它贡献 `Computer Use` 设置栏目，绑定 Host 拥有的 `computer-use` 设置命名空间，读取仅限回环地址的运行状态，启动 macOS 权限引导，打开已解压的 Chrome 扩展目录并复制配对信息。它还在会话右侧提供可伸缩的浏览器工作区：用户可在隔离浏览器与已配对 Chrome 之间切换，通过同一个搜索／地址框打开网页，在真实标签页栏中新增、切换和关闭页面，查看实时截图、暂停智能体、人工点击接管，并检查最近步骤、页面元素和截图状态。侧栏、对话与浏览器始终共同分配窗口宽度；拖动分隔线或用键盘调整时，一侧增大、相邻区域同步缩小，不再互相覆盖。窄工作区会压缩标签宽度并允许横向滚动，而不会隐藏当前页面或主要控制。

所有 `computer_*` 与 `browser_*` 工具继续使用紧凑的 DSH 原生动作行，替代通用卡片；浏览器运行时有活动任务时，工作区会自动打开，普通会话不会额外加载浏览器页面。

工作区入口与 Computer Use 设置目录复用同一个单色小电脑图标，两处入口保持一致，并自动继承周围文字颜色。入口提示固定显示在顶栏控件下方，不再遮住相邻的 Session log 操作。

## Model Experience

None, as 本包只在浏览器中渲染设置与已持久化的工具事件；所有面向模型的 schema 与 steering 消息均由 Host Computer Use 包负责。

#### KV Cache effect

None；浏览器展示不会组装或发送模型请求。

## Known Limitations and Deferred Work

- **历史截图预览仍由会话附件系统负责** — 右侧工作区只展示当前会话最近一次实时浏览器画面；工具历史中的完整图像继续由会话附件渲染器拥有。
