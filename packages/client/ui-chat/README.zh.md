# `@deepseek-ai/dsh-client-ui-chat`

[English](README.md) | 中文

Web UI 的原生纯聊天入口。本包在 `sidebar.primary.action` 中填入**开始聊天**；存在空白聊天会话时直接复用，否则以内部 `chat` agent 预设只创建一个会话再打开。并发点击共享同一次创建，但每次点击仍登记新的导航意图：如果创建完成前又点击了**开始工作**或再次点击**开始聊天**，只有最后一次手势可以打开其结果。原有**开始工作**链路和工作区归属保持不变。

内部预设只组装 `@deepseek-ai/dsh-persona`：没有工具、项目规则、工作目录上下文、权限选择、工作模式选择、工作区选择器、命令或 Skill。聊天会话仍复用普通的持久会话日志、模型选择、流式对话、标题生成、搜索与历史加载；输入框加号只是产品级上传入口，图片走现有持久附件链路，小型可读文本文件进入草稿，不授予文件系统访问权。[`ui-workspace`](../ui-workspace/README.zh.md) 把它们放进位于所有工作区之前的**聊天**分组；[`ui-conversation`](../ui-conversation/README.zh.md) 继续使用同一套对话外壳，只省略工作专属控件。

`ChatStarter` 在点击时读取共享会话列表。已有空白聊天时不会重复创建；新建请求只发送 `agentPreset: chat`，不携带工作区或 cwd，运行时从创建响应把该预设立即写入列表投影。`chat` 属于产品内部预设，不出现在 agent 预设选择器和管理页面中。

## 模型体验

### 聊天人格

#### 模型看到什么

`chat` agent 预设提供一段完整的聊天人格提示词，不提供任何工具。它要求模型作为通用聊天助手回答，不能声称自己执行了文件、命令、浏览器、项目或系统操作。

#### Token 影响

每个聊天会话带一段很短且稳定的 system prompt。请求不包含工作区规则、项目运行上下文、Skill 目录和工具 schema，因此固定上下文少于工作会话。

#### KV Cache 影响

提示词在会话生命周期内保持稳定，可在连续轮次间复用缓存。

## 已知限制与后续工作

- **聊天有意不具备执行能力**——不能读文件、运行命令、浏览网页、使用 Skill 或操作电脑；这些任务需要开始工作会话。
- **仍然需要配置模型**——该功能移除的是 Agent 能力，不是模型提供方依赖。
- **聊天复用普通会话生命周期**——删除、标题生成、搜索和历史保留沿用工作会话的产品行为，不建立第二套存储。
