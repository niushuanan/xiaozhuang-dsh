# Generated companion frames

English | [中文](README.zh.md)

These ten production sprites were generated for Xiaozhuang DSH with the built-in ImageGen workflow, then background-cleaned, trimmed, resized to a consistent 512 × 512 transparent canvas, and PNG-compressed.

The shared identity prompt describes an adult anime companion in a whale-shaped hoodie, fully dressed, with a crisp UI-sprite silhouette and no text, border, ground shadow, or background. State edits preserve the identity while changing only pose and task cue: idle, focused work with a tablet, waiting, success, and sleep. The black skin edits preserve each pose while changing the whale hoodie and outfit to matte black and charcoal with restrained cyan accents.

Runtime display size is intentionally much smaller than the source canvas. The larger source keeps facial and whale-hood details legible on Retina displays while the UI remains compact.
