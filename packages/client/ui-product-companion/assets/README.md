# Generated companion frames

English | [中文](README.zh.md)

The `v2/` directory contains 60 production frames generated for Xiaozhuang DSH with the built-in ImageGen workflow, then cut from five six-frame sheets, background-cleaned, normalized to a consistent 384 × 384 transparent canvas, and PNG-compressed. `source-v2/` preserves the generated adult character reference and the five original blue sheets used for the cut.

The shared identity prompt defines one clearly adult 27-year-old anime woman with mature proportions, long navy hair, a whale-tail ornament, opaque professional futuristic clothing, and no childlike, school, lingerie, nude, or explicit cues. Five source sheets cover sidebar, header, composer, task lifecycle, and quiet/rest interaction. Every sheet uses a 3 × 2 layout with six consistent frames. The Night Black runtime frames are deterministic palette variants of the same cleaned silhouettes, keeping identity and timing exactly aligned with Deep Sea Blue.

Runtime display size remains intentionally smaller than the 384 px source canvas. The larger source keeps the face, hair, outfit, hands, and habitat contact details legible on Retina displays while the overlay remains compact.
