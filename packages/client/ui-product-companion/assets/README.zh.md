# 生成式伙伴帧

[English](README.md) | 中文

这十张生产用精灵图通过 Xiaozhuang DSH 内置的 ImageGen 工作流生成，随后统一清理背景、裁切、缩放到 512 × 512 透明画布，并压缩为 PNG。

共享身份提示词描述了一位穿着完整、身着鲸鱼连帽服的成年日漫伙伴，轮廓适合 UI 精灵图，不含文字、边框、地面阴影或背景。各状态编辑保持同一身份，只改变姿态与任务线索：空闲、使用平板专注工作、等待、完成和睡眠。黑色皮肤保留每个姿态，只把鲸鱼帽衫和服装改为哑光黑与炭灰，并使用克制的青色点缀。

运行时显示尺寸刻意小于源画布。较大的源图可以在 Retina 屏幕上保留面部和鲸鱼帽细节，同时让实际界面继续保持紧凑。
