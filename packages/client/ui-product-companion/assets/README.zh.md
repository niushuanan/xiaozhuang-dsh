# 生成式伙伴帧

[English](README.md) | 中文

`v2/` 目录包含 60 张生产运行帧：先通过 Xiaozhuang DSH 内置 ImageGen 工作流生成五张六帧源图，再逐格切割、清理背景、统一到 384 × 384 透明画布并压缩为 PNG。`source-v2/` 保留成年角色母版和用于切帧的五张蓝色源图。

共享身份提示词定义了一位明确为 27 岁、成熟比例、深蓝长发、鲸尾发饰、穿着不透明职业科技服装的成年日漫女性，并明确排除幼态、校服、内衣、裸露和色情表达。五张源图分别覆盖目录、页头、输入区、任务生命周期和安静／休息交互，每张都是 3 × 2 的六格连续动作。夜航黑运行帧由同一组已清理轮廓确定性换色得到，因此与深海蓝保持完全一致的身份和时序。

运行时显示尺寸刻意小于 384 px 源画布。较大的源图可以在 Retina 屏幕上保留面部、长发、服装、手部和停靠接触细节，同时让实际界面继续保持紧凑。
