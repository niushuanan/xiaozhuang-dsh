# @deepseek-ai/dsh-client-ui-product-companion

[English](README.md) | 中文

Xiaozhuang DSH 的原生跨页面产品伙伴插件。角色名为**澜汐**，取自深海波澜与潮汐节律，用一个简洁、独立的姓名承接 DeepSeek 蓝、鲸系符号与成年日漫形象，而不是继续使用泛化的宠物昵称。插件向 `shell.overlay` 增加一个独立入口，因此切换对话、设置栏目和产品页面时，澜汐仍保持挂载。她直接读取已有会话列表投影，根据真实任务状态切换生成帧，不会额外发起模型请求：

- 有任务运行时进入**工作**状态。
- 任务需要批准、回答问题或审阅计划时进入**等待**状态。
- 运行任务结束后短暂进入**完成**状态。
- 工作区安静时处于**陪伴与休息**状态。

伙伴现在固定生活在真实输入框右侧正上方，不再游走到无关产品区域；可见身体刚好贴住输入框上沿，不覆盖输入文字。安静、工作、等待和完成状态继续保持趴姿。发送消息或布局回流导致输入框移动时，六张传送门原画会取代原来的爬行：澜汐在旧锚点站起并开门，完全进入门内后才切换根节点坐标，再把同一组原画反向播放，从新锚点走出并恢复趴姿。整个过程的根节点框、图片层、人物最长可见轴和输入框基线都保持不变，运行时绝不使用 `scale()`。插件通过 `MutationObserver`／`ResizeObserver` 连续测量真实位置；一次传送中出现的多次布局变化会自动合并到最新目标，输入框不动时角色也不会位移。单击、双击与右键仍可分别配置；默认依次为聚焦输入框、继承当前工作区新建对话、打开包含新建／聚焦／关闭的产品菜单。动画使用 24 fps 曝光表并由 `requestAnimationFrame` 采样，预解码原画只在一个始终不透明的图片元素上替换。

一条紧凑提示会显示当前真实任务的会话标题、阶段和已用时间，但不会把无法确定的模型响应伪装成百分比进度。澜汐下方的数字是全产品正在运行或等待确认的对话总数；点击后按优先级展开独立任务气泡，先显示需要用户处理的任务，再显示当前对话和最近更新的后台任务。气泡从靠近角色的一端开始逐个向上出现；点击任意气泡会通过现有 Session Runtime 跳转，但整组任务仍保持展开，用户可以继续在并发任务之间切换。再次点击数字、按 Escape 或点击外部，气泡会按相反顺序自然回落并收起。左侧语音波形是明确禁用的 AI 语音输入预告，悬停会说明“敬请期待”，不会伪装成已经可用。时间从浏览器插件实际观察到运行状态开始计算；输入检测只保留“输入框是否非空”的布尔值，不保存提示词或生成中的消息正文。偏好统一放在独立的**澜汐**设置栏目，包含蓝黑换肤、标准／放大尺寸、三种快捷动作、显示／隐藏和任务状态提示。右键关闭会保存在本机，同一个设置开关可以重新开启。设置弹窗出现时澜汐会主动退场，弹窗关闭后再回到输入框，不遮挡配置内容。V8 使用四条趴姿语义循环、一条固定尺度的传送门过渡和 124 张透明运行素材。明确成年的角色保留用户认可的脸型、纤细比例、DeepSeek 鲸系首饰和非露骨的性感时装语言；深海蓝和夜航黑共用完全一致的透明轮廓。浏览器会提前解码当前皮肤的 62 张素材，素材回归会检查透明边缘、统一趴姿镜头、蓝黑轮廓一致、语义循环稳定和传送门体感尺寸一致。

Host 端只从 `/plugins/ui-product-companion/assets/v8` 提供 124 张白名单内的不可变运行素材；浏览器端负责状态判断、输入存在性判断、24 fps 曝光表播放、输入框几何监测和两阶段传送门过渡。模型用量这类非模态产品面板不会卸载澜汐，只有真正独占整个界面的模态窗口会让她暂时让出画布。停用 `ui-product-companion` Loader 配置行会立即热卸载澜汐，不会改变会话、目录、对话界面或其他插件；重新启用同一配置行会在不重启 Web 进程的情况下再次挂载这个独立入口。

## 模型体验

无，因为伙伴只消费已有投影状态，不组装提示词，也不发送模型请求。

#### KV Cache 影响

无。

## 已知限制与暂缓工作

- 插件有意不加入第二个聊天框、喂养、货币、成长或小游戏。这些概念会重复主产品流程，并增加长期注意力成本。
- 插件挂载前已经完成的任务不会补播完成动作；只庆祝真实发生的“运行中 → 已结束”转换。
- 用时是浏览器实际观察到的时间；如果任务运行中刷新页面，本地计时会重新开始，不会伪造刷新前的起点。
- 只有页面存在真实输入框时才显示角色；设置弹窗和没有输入框的页面会主动留白。
- AI 语音输入入口目前只是禁用预告，不会请求麦克风权限；真正的语音输入法将在后续插件迭代中接入。
