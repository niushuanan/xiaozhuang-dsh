# @deepseek-ai/dsh-client-ui-product-companion

[English](README.md) | 中文

Xiaozhuang DSH 的原生跨页面产品伙伴插件。插件向 `shell.overlay` 增加一个独立入口，因此切换对话、设置栏目和产品页面时，角色仍保持挂载。它直接读取已有会话列表投影，根据真实任务状态切换生成帧，不会额外发起模型请求：

- 有任务运行时进入**工作**状态。
- 任务需要批准、回答问题或审阅计划时进入**等待**状态。
- 运行任务结束后短暂进入**完成**状态。
- 工作区安静时处于**陪伴与休息**状态。

角色本身就是交互面。单击只会在当前位置做一次短回应，不会再把她送回目录，也不会打开另一张卡片；只有拖动才会直接改变位置。拖到目录、页头或输入区附近会吸附到对应真实组件，每个位置都有自己独立的六帧动作，不再复用一张通用姿态。工作区安静时会在原地眨眼、伸展、观察和休息；开启任务跟随后，任务运行或等待确认时才会靠近输入区，并播放任务与完成连续帧。

一条紧凑提示会映射本轮真实状态，但不会把无法确定的模型响应伪装成百分比进度：**正在回应 · 12 秒**、**等待你确认 · 12 秒**，结束后显示**已完成 · 12 秒**。时间从浏览器插件实际观察到运行状态开始计算，不读取提示词或生成中的消息正文。偏好统一放在独立的**小鲸灵**设置栏目，包含蓝黑换肤、任务状态提示、自动跟随任务和一次明确的恢复默认位置。语义停靠点、自由位置、皮肤与行为偏好只保存在本机。两套皮肤共使用 60 张生成透明帧，覆盖目录、页头、输入区、任务和休息五组动作；浏览器只预加载当前皮肤的 30 帧。

Host 端只从 `/plugins/ui-product-companion/assets/v2` 提供 60 张白名单内的不可变运行帧；浏览器端负责全部状态判断、逐帧时序与交互。删除或停用 Loader 配置行即可移除伙伴，不会改变会话、目录或对话界面。

## 模型体验

无，因为伙伴只消费已有投影状态，不组装提示词，也不发送模型请求。

#### KV Cache 影响

无。

## 已知限制与暂缓工作

- 插件有意不加入第二个聊天框、喂养、货币、成长或小游戏。这些概念会重复主产品流程，并增加长期注意力成本。
- 插件挂载前已经完成的任务不会补播完成动作；只庆祝真实发生的“运行中 → 已结束”转换。
- 用时是浏览器实际观察到的时间；如果任务运行中刷新页面，本地计时会重新开始，不会伪造刷新前的起点。
- 自由放置的位置仍按视口坐标保存，显示器尺寸大幅变化时会限制回可见区域；目录、页头和输入框停靠点使用语义锚点，会按当前页面布局重新计算。
