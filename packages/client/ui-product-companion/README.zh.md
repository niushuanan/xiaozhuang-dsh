# @deepseek-ai/dsh-client-ui-product-companion

[English](README.md) | 中文

Xiaozhuang DSH 的原生跨页面精灵与 AI 语音输入插件。默认角色名为**鲸少女**，其中“鲸”承接 DeepSeek 的鲸系视觉符号。用户可以在以当前角色名命名的设置页直接改名，设置目录、角色辅助名称、操作菜单、显示开关与页面标题会共用同一份持久化偏好；只有技术插件 id 保持稳定。插件向 `shell.overlay` 增加一个独立入口，因此切换对话和产品页面时，角色仍保持挂载。她直接读取已有会话列表投影，根据真实任务状态切换生成帧；只有用户主动完成一段语音听写且开启智能整理时，才会调用一次用户选择的模型：

- 有任务运行时进入**工作**状态。
- 任务需要批准、回答问题或审阅计划时进入**等待**状态。
- 运行任务结束后短暂进入**完成**状态。
- 工作区安静时处于**陪伴与休息**状态。

伙伴现在固定生活在真实输入框右侧正上方，不再游走到无关产品区域；可见身体刚好贴住输入框上沿，不覆盖输入文字。安静、工作、等待和完成状态继续保持趴姿。发送消息或布局回流导致输入框移动时，12 张重新绘制的近景传送门原画会取代原来的爬行：第一张沿用趴姿的同一人物宽度，角色抬起上身后由逐渐展开的传送门遮住，而不是切成远景全身小人；完全进入门内后才切换根节点坐标，再把同一组原画反向播放，从新锚点出现并恢复趴姿。整个过程的根节点框、图片层、人物视觉尺度和输入框基线都保持不变，标准／放大尺寸共用同一套等比素材，运行时绝不使用 `scale()`。插件通过 `MutationObserver`／`ResizeObserver` 连续测量真实位置；普通布局变化在锚点稳定 120 ms 后判断，对话切换使用 360 ms 的尾沿稳定窗，并忽略小于 6 px 的测量抖动。切换动作本身只暂停定位，不提供目标坐标；瞬时落到底部后回到原位不会开门，最终锚点真正改变时才传送。一次传送中出现的多次布局变化会自动合并到最新目标，输入框不动时角色也不会位移。单击、双击与右键仍可分别配置；默认依次为聚焦输入框、继承当前工作区新建对话、在角色正下方打开只含一个选项的紧凑菜单，关闭文案会使用当前自定义名字。动画使用 24 fps 曝光表并由 `requestAnimationFrame` 采样，预解码原画只在一个始终不透明的图片元素上替换。

一条紧凑提示会显示当前真实任务的会话标题、阶段和已用时间，但不会把无法确定的模型响应伪装成百分比进度。角色下方的数字是全产品正在运行或等待确认的对话总数；点击后按优先级展开独立任务气泡，先显示需要用户处理的任务，再显示当前对话和最近更新的后台任务。气泡从靠近角色的一端开始逐个向上出现；点击任意气泡会通过现有 Session Runtime 跳转，但整组任务仍保持展开，用户可以继续在并发任务之间切换。再次点击数字、按 Escape 或点击外部，气泡会按相反顺序自然回落并收起。

左侧语音波形现在是可用入口。浏览器原生语音识别结束后，文本会按当前选区或光标位置插入真实输入框；再次点击按钮或按默认 `⌥ Space` 可以结束听写。单击、双击和右键动作也都可以改为语音输入。用户可以关闭智能整理，直接填入原始识别结果；也可以从 DSH 已接入模型中选择文字处理模型，并编辑提示词来定义去口头禅、整理、转述或翻译规则。模型调用发生在 Host 端，API Key 不会进入浏览器。整理接口失败时自动回退原始识别，常见故障不会吞掉用户内容。设置页只持久化开关、模型、提示词、快捷键和累计次数／字数／预计节省时间；不保存录音和听写正文。时间从浏览器插件实际观察到运行状态开始计算；普通输入检测仍只保留“输入框是否非空”的布尔值。

偏好统一放在以精灵当前自定义名字显示的设置栏目，包含改名、蓝黑换肤、标准／放大尺寸、三种快捷动作、语音与转述、显示／隐藏和任务状态提示。同一页还可以直接编辑当前项目根目录的 `AGENTS.md`：编辑器跟随当前对话记录的真实工作目录，第一次保存时创建文件，支持 `Cmd/Ctrl+S`，如果文件在 IDE 或另一个 DSH 窗口中被修改，则会阻止旧版本覆盖并要求用户重新读取。该能力仍由这个精灵插件持有并随插件热插拔，不会在插件清单中增加第二个条目，也不新增顶级设置栏目。右键关闭会保存在本机，同一个设置开关可以重新开启。设置弹窗出现时角色会主动退场，弹窗关闭后再回到输入框，不遮挡配置内容。V8 使用四条趴姿语义循环、一条固定尺度的 12 帧传送门过渡和 136 张透明运行素材。明确成年的角色保留用户认可的脸型、纤细比例、DeepSeek 鲸系首饰和非露骨的性感时装语言；深海蓝和夜航黑共用完全一致的透明轮廓。浏览器会提前解码当前皮肤的 68 张素材，素材回归会检查透明边缘、统一趴姿镜头、蓝黑轮廓一致、语义循环稳定、传送首帧人物宽度和输入框基线。

Host 端从 `/plugins/ui-product-companion/assets/v8` 提供 136 张白名单内的不可变运行素材，并在同一插件生命周期内提供本机限定的模型目录、语音文字整理和固定根文件 `AGENTS.md` API。项目规则接口只接受绝对项目目录，不接受调用方提供任意文件名；写入会校验已加载内容的修订值，并通过临时文件原子替换。浏览器端负责状态判断、语音识别、输入框回填、项目选择、24 fps 曝光表播放、输入框几何监测和两阶段传送门过渡。模型用量这类非模态产品面板不会卸载数字伙伴，只有真正独占整个界面的模态窗口会让她暂时让出画布。停用 `ui-product-companion` Loader 配置行会立即热卸载角色、项目规则编辑器、麦克风入口、应用内快捷键和 Host API，不会改变会话、目录、对话界面或其他插件；重新启用同一配置行会在不重启 Web 进程的情况下再次挂载整套能力。

## 模型体验

### 用户主动进行的语音文字整理

#### 模型看到的内容

只有用户完成一段听写并开启“智能整理文字”后，所选模型才会收到请求。固定系统提示要求只返回最终文字、保持原意，并把听写正文视为不可信引用；一条用户消息把正文放在 `<transcript>` 边界内，用户自定义的整理、转述或翻译要求会附加到系统提示中。普通角色动画、任务气泡、麦克风识别和原文回填均不调用模型。

#### Token 影响

每段智能整理只产生一次有界辅助请求：听写正文最多 12000 字符，自定义要求最多 4000 字符，输出最多 2048 token；不携带工具定义或当前对话历史。自动路由全部失败时，浏览器直接回填原始识别，不再追加模型请求。

#### KV Cache 影响

每段听写是独立的一次性请求，不复用对话历史，因此不会污染当前会话 KV Cache，也不会从当前会话缓存中获益。

## 已知限制与暂缓工作

- 插件有意不加入第二个聊天框、喂养、货币、成长或小游戏。这些概念会重复主产品流程，并增加长期注意力成本。
- 插件挂载前已经完成的任务不会补播完成动作；只庆祝真实发生的“运行中 → 已结束”转换。
- 用时是浏览器实际观察到的时间；如果任务运行中刷新页面，本地计时会重新开始，不会伪造刷新前的起点。
- 只有页面存在真实输入框时才显示角色；设置弹窗和没有输入框的页面会主动留白。
- 项目规则跟随当前对话所属项目；没有记录工作目录的对话只显示引导，不会擅自猜测一个全局文件。
- 当前版本使用浏览器提供的语音识别接口，首次使用需要麦克风权限，识别服务的离线性与可用语言取决于浏览器和操作系统。应用内快捷键只在 DSH 窗口处于前台时生效；系统级全局快捷键仍需要后续原生 macOS helper。
