# @deepseek-ai/dsh-client-ui-product-companion

[English](README.md) | 中文

Xiaozhuang DSH 的原生跨页面精灵与麦克风听写插件。默认角色名为**鲸少女**，其中“鲸”承接 DeepSeek 的鲸系视觉符号。用户可以在以当前角色名命名的设置页直接改名，设置目录、角色辅助名称、操作菜单、显示开关与页面标题会共用同一份持久化偏好；只有技术插件 id 保持稳定。插件向 `shell.overlay` 增加一个独立入口，因此切换对话和产品页面时，角色仍保持挂载。她直接读取已有会话列表投影，根据真实任务状态切换生成帧：

- 当前对话开始运行或任务确有更新时短暂进入一次**工作**动作，随后稳定停住。
- 任务需要批准、回答问题或审阅计划时进入**等待**状态。
- 运行任务结束后短暂进入**完成**状态。
- 工作区安静时处于**陪伴与休息**状态。

伙伴生活在真实输入框正上方，水平泊位可由用户沿卡片任意拖动：拖放后的偏移以 0–1 比例持久化，输入框此后无论移动还是变宽窄，她都回到同一个相对位置；没有偏好时默认停靠右缘。可见身体刚好贴住输入框上沿，不覆盖输入文字。安静、工作、等待和完成状态继续保持趴姿。工作态刻意低干扰：不再叠加独立的整身摇摆，后台会话只更新任务数字和列表，不会带动人物动画。V14 角色原画统一收窄腰部以下轮廓，并在臀腿、抬起的双腿和靴子周围增加透明留白；两段前臂护甲统一改为珍珠白、极浅冰蓝高光和细钴蓝收边，黑色手套、蓝色上臂甲和深色主体保持不变。四种状态与蓝黑皮肤共用同一材质层级和纤细比例，因此手臂不再糊进躯干，切换 Agent 阶段也不会忽胖忽瘦。

精灵画面继续显示在产品上层，但不会占走矩形范围内的每一次左键。人物覆盖原生输入框、按钮、链接、选择器或编辑区时，左键优先交给底层控件；只有下方没有可操作内容时，才执行精灵已配置的单击或双击。右键仍保留精灵自己的关闭／菜单动作。

输入框真实换位时，插件冻结当前人物原画与尺寸，并把 48 张 V13 身体遮罩直接应用到这一张角色图。遮罩只从 136 张生产人物帧的真实像素并集取材，靴子、发梢和服装外缘先碎成保留原像素颜色的细小片段，脸部直到最后阶段才消散；不会出现角色之外的随机泡沫。完全消失后才切换固定尺寸根节点坐标，到达阶段严格反放同一序列，让同一个人物从自身材质中重新聚合。麦克风与任务数圆键也共用这套生命周期：离场早期禁用并淡出，隐藏坐标切换时保持不可见，只在新锚点的角色重新聚合时恢复可见。单程 1040 ms，相邻遮罩以 28 ms 淡出衔接；标准 132 × 118 与放大 164 × 147 始终共用同一人物原画，不再出现独立泡沫云、门体、缩放或第二套人物。插件通过 `MutationObserver`／`ResizeObserver` 连续测量真实位置；普通布局变化在锚点稳定 120 ms 后判断，对话切换使用 360 ms 的尾沿稳定窗，并忽略小于 6 px 的测量抖动。瞬时落到底部后回到原位不会触发消散，最终锚点真正改变时才换位；一次过渡中的多次布局变化会自动合并到最新目标。单击、双击与右键仍可分别配置。语义动作继续使用 24 fps 曝光表，但浏览器只提前解码当前动作的后两帧和下一组消散遮罩，不会在挂载时一次处理全部 152 份素材。

一条紧凑提示会显示当前真实任务的会话标题、阶段和已用时间，但不会把无法确定的模型响应伪装成百分比进度。角色下方的数字是全产品正在运行或等待确认的对话总数；点击后按优先级展开独立任务气泡，先显示需要用户处理的任务，再显示当前对话和最近更新的后台任务。气泡从靠近角色的一端开始逐个向上出现；点击任意气泡会通过现有 Session Runtime 跳转，但整组任务仍保持展开，用户可以继续在并发任务之间切换。再次点击数字、按 Escape 或点击外部，气泡会按相反顺序自然回落并收起。

左侧语音波形直接调用浏览器麦克风。按钮在空闲与听写时始终保持黑底白色波形，听写中只播放波形节奏，不改变人物语义动作；悬停不改变按钮，也不生成提示层。浏览器原生识别出的原文会按当前选区或光标位置插入真实输入框；再次点击按钮或按默认 `⌥ Space` 可以结束听写，单击、双击和右键动作也都可以绑定这项能力。产品不设置听写倒计时；如果浏览器因为静默或服务轮换结束一段底层识别，插件会保留已识别文字并自动开始下一段，直到用户主动停止、关闭功能或系统拒绝权限。听写链路不读取模型目录、不调用大模型、不做 AI 润色，不保存录音和听写正文；设置页只保留麦克风开关与应用内快捷键。普通输入检测仍只保留“输入框是否非空”的布尔值。

偏好统一放在以精灵当前自定义名字显示的设置栏目，包含改名、蓝黑换肤、标准／放大尺寸、三种快捷动作、麦克风听写、显示／隐藏和任务状态提示。改名输入区使用固定紧凑宽度并为聚焦描边保留顶部空间，说明只保留一句用途，不会再越出设置窗口。此页还直接编辑 `~/.dsh/AGENTS.md`：DSH 会在每个模型步骤重新读取已保存文件，并作为受保护的最后 system 段注入，高于其他全部 DSH 指令。编辑器打开时读取完整最新内容，页面可见且草稿未修改时会自动同步外部变化；保存按钮始终叫“保存修改”，成功后从所有对话的下一轮起生效。若文件在 IDE 或另一个 DSH 窗口中被修改，旧草稿不会覆盖新版本，用户可以明确载入最新内容。编辑入口仍由精灵插件持有并随插件热插拔，指令权限由 Host 提示词链路保证。右键关闭会保存在本机，同一个设置开关可以重新开启。V14 保存已验收的纤细趴姿语义人物原画和轻色护臂；V13 只包含 48 张身体遮罩和 48 张片段遮罩，不包含另一套人物。浏览器只在播放前解码当前语义相邻帧和下一组消散遮罩，并对同一挂载实例去重；素材回归检查护臂在蓝黑皮肤中保持可读、遮罩只落在真实人物像素内、材质单调消散、人物地址与外框恒定、同源加载和完全消失后的坐标切换。

Host 端从 `/plugins/ui-product-companion/assets` 提供白名单内的 V14 人物帧和 V13 身体材质遮罩，并在同一插件生命周期内提供固定全局 `AGENTS.md` API。规则接口通过 DSH Home 解析器只读写当前运行实例实际使用的 `~/.dsh/AGENTS.md`，不接受浏览器提供项目目录或任意文件名；写入会校验已加载内容的修订值，并通过同目录临时文件原子替换。浏览器端负责状态判断、麦克风语音识别、输入框回填、语义曝光表播放、输入框几何监测、规则自动同步和两阶段身体消散换位。模型用量这类非模态产品面板不会卸载数字伙伴，只有真正独占整个界面的模态窗口会让她暂时让出画布。停用 `ui-product-companion` Loader 配置行会立即热卸载角色、全局规则编辑器、麦克风入口、应用内快捷键和 Host API，不会改变会话、目录、对话界面或其他插件；重新启用同一配置行会在不重启 Web 进程的情况下再次挂载整套能力。

## 模型体验

Indirectly, through 已保存的 `~/.dsh/AGENTS.md`——Host 提示词流水线在每个模型步骤重新读取，并将其作为受保护的最后 system 段注入。

#### KV Cache effect

文件不变时注入段保持稳定，其 token 可在请求间复用；保存后从下一轮起该段变化，复用自这些 token 起失效。

## 已知限制与暂缓工作

- 插件有意不加入第二个聊天框、喂养、货币、成长或小游戏。这些概念会重复主产品流程，并增加长期注意力成本。
- 插件挂载前已经完成的任务不会补播完成动作；只庆祝真实发生的“运行中 → 已结束”转换。
- 用时是浏览器实际观察到的时间；如果任务运行中刷新页面，本地计时会重新开始，不会伪造刷新前的起点。
- 只有页面存在真实输入框时才显示角色；设置弹窗和没有输入框的页面会主动留白。
- 保存全局规则后，已在进行中的当前模型调用不会被中途改写；所有对话从各自下一轮开始读取新内容。
- 当前版本使用浏览器提供的语音识别接口，首次使用需要麦克风权限，识别服务的离线性与可用语言取决于浏览器和操作系统。应用内快捷键只在 DSH 窗口处于前台时生效；系统级全局快捷键仍需要后续原生 macOS helper。
