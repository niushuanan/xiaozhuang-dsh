# @deepseek-ai/dsh-client-ui-outline

[English](README.md) | 中文

对话大纲插件。`OutlineRail` 填充常驻会话外壳的增量槽位 `conversation.session.outline`：当当前对话的用户轮数达到三轮及以上时，在对话列左缘渲染一条窄刻度轨。

每个刻度对应用户的一轮提问，全部从会话套件的标准 chat 快照（`chat.order` + `chat.nodes`）推导：轮次从一条可见的 `user` 消息开始，预览携带截断的问题文本与该轮第一条助手消息的开头文本，刻度宽度按该轮助手文本总长的分档变化，使轨道呈现对话的形态。插话、注入上下文与工具节点不会开启轮次。滚动侦测跟随对话滚动容器（同列下的 `[data-conversation-scroll]`）的滚动事件与聊天流的尺寸变化，标出阅读线以上最后一轮的位置，当前刻度加深。点击刻度把该轮已渲染的行（`data-chat-anchor-key`）平滑滚动到视口顶部，走聊天视图既有的滚动记账。悬停刻度在锚定于刻度的穿透卡片中预览该轮。

座位本身由会话骨架持有的零宽穿透覆盖层，在内嵌窗格、分屏布局与多窗格分组下隐藏；轨道只对自身重新启用指针事件，轮数不足阈值时什么也不渲染。目标槽位由另一插件声明，因此 `apply` 使用 `slots.inject()` 按声明生命周期注册，并在声明恢复后重新注册。

## Model Experience

无：大纲是浏览器界面元素，不触及模型请求。

#### KV Cache effect

无；本包既不组装也不发送 provider 请求。

## Known Limitations and Deferred Work

- **轮次探测跟随已渲染行**——滚动侦测与跳转遍历聊天视图的锚点 DOM，尚未分页载入的历史轮次没有刻度，载入后才会出现。
- **进行中轮次的摘要补齐较晚**——轮次预览在存在助手消息后显示回答文本；流式进行中的轮次在消息定稿或下一轮开始前只显示问题。
- **超长对话裁剪轨道**——轨道以列高为上限且不分页，极多轮次时溢出部分不可见，而不会进一步缩小。
