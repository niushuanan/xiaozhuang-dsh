# @deepseek-ai/dsh-client-ui-outline

[English](README.md) | 中文

对话大纲插件。`OutlineRail` 填充常驻会话外壳的增量槽位 `conversation.session.outline`：当已载入的历史窗口覆盖三轮及以上时，在对话列左缘渲染一条窄刻度轨。

每个刻度对应一轮，全部从会话套件的标准 chat 快照（`chat.order` + `chat.nodes`）推导：轮次边界跟随每条可见行的 `location.turn`——提问行不 gate 推导，因为编码视图不渲染提问行，且首页历史可能覆盖若干轮而它们的提问落在窗口之外。`user`/`steering` 行把截断文本贡献给下一轮的预览；预览在有提问时显示问题，无论如何都显示该轮第一条助手消息的开头文本，刻度宽度按该轮助手文本总长分档，使轨道呈现对话形态。滚动侦测跟随对话滚动容器（同列下的 `[data-conversation-scroll]`）的滚动事件与聊天流的尺寸变化，标出阅读线以上最后一轮的位置，当前刻度加深。点击刻度把该轮已渲染的行（`data-chat-anchor-key`）平滑滚动到视口顶部，走聊天视图既有的滚动记账。悬停刻度在锚定于刻度的穿透卡片中预览该轮。

工具量巨大的会话首页可能覆盖不了三轮；窗口不足阈值且还有更早历史时，轨道经会话对象面的 `loadOlder` 有界回拉更早历史（每次挂载至多三页），达到阈值前什么也不渲染。

座位本身由会话骨架持有的零宽穿透覆盖层，在内嵌窗格、分屏布局与多窗格分组下隐藏；轨道只对自身重新启用指针事件。目标槽位由另一插件声明，因此 `apply` 使用 `slots.inject()` 按声明生命周期注册，并在声明恢复后重新注册。

## Model Experience

无：大纲是浏览器界面元素，不触及模型请求。

#### KV Cache effect

无；本包既不组装也不发送 provider 请求。

## Known Limitations and Deferred Work

- **轮次探测跟随已渲染行**——滚动侦测与跳转遍历聊天视图的锚点 DOM，尚未分页载入的历史轮次没有刻度；轨道每次挂载自动回拉至多三页，更早的历史仍需手动翻页。
- **进行中轮次的摘要补齐较晚**——轮次预览在存在助手消息后显示回答文本；流式进行中的轮次在消息定稿或下一轮开始前只显示问题。
- **超长对话裁剪轨道**——轨道以列高为上限且不分页，极多轮次时溢出部分不可见，而不会进一步缩小。
