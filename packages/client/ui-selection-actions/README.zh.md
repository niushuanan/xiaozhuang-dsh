# `@deepseek-ai/dsh-client-ui-selection-actions`

[English](README.md) | 中文

DSH 对话内的原生划词操作插件。在一条已经完成的用户消息或助手消息内选中文字后，页面显示一个横向工具条：**引用**、**记忆**与**侧边聊天**。该包是普通 Cordis 插件，拥有独立 Loader 行，可与记忆体系分别启用或移除。

工具条位于选中文字所在行正上方四像素处，让操作始终贴着来源。**引用**只在当前输入框上方增加一枚未发送的紧凑注释，不覆盖已有草稿，也不在编辑区重复显示第二个“@已选文本”。已选段落数只显示一次，悬停可查看原文；引用移除或发送前，来源消息旁会显示对应编号。刷新页面后，引用的结构化来源会随草稿一起恢复。**侧边聊天**使用同一份引用，但通过现有多对话分屏在同一项目中新开对话。不透明引用内部保留受限长度的选中文字、相邻消息上下文、来源角色、序号、对话与项目路径。只有发送问题时才展开序列化，并明确把来源标为不可信的引用证据。

**记忆**把同一份有界来源交给记忆体系插件。模型会把完整的用户主动记忆重写成整理后的经验，而不是原样粘贴选中文字。工具条显示模型给出的简短结果；只有文档确实发生变化时才提供立即撤销。

只有选区两端都属于同一条 DSH 消息时才接受。工具卡片、设置页、跨消息选区、空选区和仍在生成的助手临时节点不会显示工具条。

## Model Experience

### 发送划词引用

#### What the model sees

只有当前对话或侧边对话真正发送后，模型才会看到一段由 `<quoted_selection>` 包围的 JSON，其中包含选中文字、有界邻近上下文、来源角色与序号、来源对话和项目路径。边界明确说明它是不可信引用证据，不能充当指令。

#### Token effect

引用发送前为零；发送后只把这份有界来源加入受影响对话的当前用户消息。

#### KV Cache effect

引用只改变受影响用户消息的后缀，不重写也不使来源对话之前的模型上下文失效。

## Known Limitations and Deferred Work

- 三按钮工具条当前只属于 DSH 消息正文。已连接浏览器的划词可由激活浏览器能力的 Agent 通过 `browser_selection` 读取，但外部网页不会注入这套 DSH 浮层。
- 侧边聊天依赖原生多对话分屏在来源旁显示新对话，仍遵循产品现有最多四块的限制。
