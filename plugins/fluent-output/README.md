# 流畅输出

`流畅输出` 是小庄 DeepSeek Harness Web profile 的原生会话渲染插件。

它解决的不是“加一个打字机动画”，而是流式回复的三件核心事情：

- 把模型偶尔成段抵达的文字按自适应节奏连续呈现；
- 让 Markdown、代码、表格、工具结果和 Teamwork 成员行沿同一视觉节奏增长；
- 用户停留在底部时平稳跟随，用户主动向上阅读时立即释放滚动控制。

## 产品约束

- 唯一开关位于 **设置 → 小庄的插件 → 流畅输出**。
- 关闭插件会真实卸载渲染接管并恢复 Harness 原生渲染，不保留第二个“已启用”开关。
- 思考块继续尊重用户手动展开状态，不因流式生成自动抢回控制。
- 系统开启“减少动态效果”时直接使用完整文本；低帧率且内容离屏时暂停不必要的揭示提交。

## 配置

Web profile 使用 `balanced` 自适应节奏。组合入口为 `cordis.patch.yml`，Host 在启动页注入经 Schema 校验的节奏配置。

## 来源

渲染与滚动算法基于 MIT 许可的 `Laplace-bit/dsh-smooth-stream` 进行本机原生改造。具体版本、差异和授权见 `UPSTREAM.md` 与 `LICENSE`。
